## ブラウザと外部サービス

- Linux WebKit 18.2で37画面すべてを幅320pxと1366pxで直接開き、タイトルと横幅を確認しました。アプリ内の画面遷移とGTKのクリップボードも確認しました。
- ChromiumとFirefoxでは、画像変換からBase64化、復元、ハッシュとHex表示までを通して照合しました。H.264/AACの逆再生結果は、対応コーデックを備えたLinux WebKit、Firefox、Debian Chromiumで内蔵プレーヤーの再生を確認しました。
- QR生成は実APIの画像を読み取りました。DNSや接続情報の障害・再試行には固定応答を使っています。Notionへの変換は文字列とクリップボードまでを確認しました。この環境のNotionはログイン画面までで、編集画面への貼り付け結果は未確認です。
- 500 MiB・2 GiBの動画は疎ファイルを使い、選択時の警告・拒否の境界を検証しました。3ツールすべてで変換まで完了した大容量動画は36,794,530バイト、1920×1080、9秒です。圧縮と逆再生は最初の試行でブラウザのページがクラッシュし、単独再実行で完走しました。上限付近の実変換、端末のメモリ容量ごとの完走、可変フレームレート素材の厳密な反転時刻は未確認です。
- Safariとスマートフォン実機はこの環境で利用できません。Linux WebKit、モバイル幅、モバイル用User-Agentで確認できた範囲を上に記載しました。
